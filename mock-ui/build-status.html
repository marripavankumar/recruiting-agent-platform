Safeguards in code

  • Nothing is sent or submitted without an approval; the send must match the approved text exactly
  • Each approval delivers at most once, even after a retry or restart
  • Opt-outs block every agent and channel; unsubscribe links are signed
  • Canadian contacts need a recorded CASL consent basis before any email
  • Outreach is off in local and dev, allow-listed in test, capped per day
  • LinkedIn requests are sent by the recruiter by hand, never automated
  • Follow-up messages use the same approval gates; follow-ups stop at the cadence limit and when a job is closed
  • A resume goes to a client only with the candidate's consent for that job, a right-to-represent confirmation and an approval; never twice to the same client

Try the real API locally

No database or API key needed:

cd backend
RAP_STORAGE=memory RAP_LLM_PROVIDER=none RAP_DEMO_USERS=true \
  uv run uvicorn recruiting.api.main:app --reload

Open http://localhost:8000/docs and send the header X-Dev-User-Email: bd.manager@cbs.example (or administrator@, recruiter@, account.manager@, sales.manager@).
