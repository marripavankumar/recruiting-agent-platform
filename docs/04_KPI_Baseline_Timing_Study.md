# KPI Baseline and Timing Study (Phase 0, activity 3)

**Status:** Template, to be filled in during Phase 0, 2026-11-22  
**Purpose:** measure today's manual effort and elapsed time, so the platform can be judged against the BRD §2 goal ("reduce manual recruiting effort by over 80%", Q12) and the §12 KPIs, including "<24 hours from JD receipt to first submission".

## 1. How to run the study

1. **Pick samples.** The plan calls for one client and one JD. Time 3 of each if you can: one sample can be unusually fast or slow.
2. **Time real work, not estimates.** The person doing the step logs start and stop times as they work. Waiting time (for example, a client not replying yet) is **elapsed time**, not effort.
3. **Log every step** in the tables below, including steps not listed (add rows). Write "not done today" for steps the current process skips.
4. **Record tools used** (LinkedIn Recruiter, a job board, Excel, Outlook, and so on). This feeds the connector inventory (activity 5).
5. **Fill in the KPI baseline (Section 4)** from the last 3 months of records, where they exist.
6. **Review** the numbers with the BD Manager and a Recruiter, then sign off (Section 6).

**Effort** = hands-on minutes by a person. **Elapsed** = clock time from the first step to the last.

## 5. Calculating the 80% target (Q12)

- **Baseline effort per client** = total effort in Section 2 (average of samples).
- **Baseline effort per JD** = total effort in Section 3 (average of samples).
- **Monthly baseline** = (effort per client × clients worked per month) + (effort per JD × JDs per month).
- **Target** = platform-era effort ≤ 20% of the baseline for the same volume.
- **What still counts as manual effort after go-live:** approvals at the four §10 gates, recruiter review of rankings and matches, manual LinkedIn sends (see compliance item C1), corrections to extracted data, and candidate calls. These are measured again in the Phase 8 pilot with this same template.
